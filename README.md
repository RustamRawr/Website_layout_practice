# Delta Collider — сайт на вымышленном движке

В данном репозитории собранны файлы HTML, CSS и JS для сайта, который я сверстал в качестве практического задания. В проекте использованы чистые технологии: HTML, CSS и JavaScript без фреймворков.

Этот проект — сайт, сделанный на основе моего собственного вымышленного движка **Delta Collider**, вдохновлённого творчеством Unreal Engine.

---

## Краткое описание особенностей 

- Чистый HTML и два подключённых CSS-файла для стилей  
- Анимации для блоков и кнопок: плавные эффекты появления, подсветка кнопок при наведении  
- **Форма** входа с анимацией, размытием фона и подсветкой элементов  
- Лёгкий и отзывчивый дизайн, который легко адаптировать
***Больше всего внимания в плане разработке было уделено форме, которая отображается на сайте при нажатии кнопки "войти" (форма ещё не доделана до финальной версии).**

---

## Технологии

- **HTML** (стандарт HTML5)  
- **CSS** (используется CSS3)  
- **JavaScript** (Vanilla JS)  

---

## Как запустить

Просто открыть файл `index.html` в любом современном браузере (был проверен в Google Chrome).
